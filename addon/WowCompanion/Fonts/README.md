# Fonts

Interface fonts the player can switch between live (Tools tab, Fonts.lua).
All are from google/fonts (https://github.com/google/fonts, `ofl/`), under the
SIL Open Font License 1.1, which allows bundling. Fetched 2026-11-10; static
Medium/Regular cuts, except Roboto Condensed (variable, default instance).

- PTSansNarrow.ttf: ofl/ptsansnarrow/PT_Sans-Narrow-Web-Regular.ttf
- FiraSansCondensed.ttf: ofl/firasanscondensed/FiraSansCondensed-Medium.ttf
- BarlowSemiCondensed.ttf: ofl/barlowsemicondensed/BarlowSemiCondensed-Medium.ttf
- IBMPlexSansCondensed.ttf: ofl/ibmplexsanscondensed/IBMPlexSansCondensed-Medium.ttf
- SairaSemiCondensed.ttf: ofl/sairasemicondensed/SairaSemiCondensed-Medium.ttf
- AtkinsonHyperlegible.ttf: ofl/atkinsonhyperlegible/AtkinsonHyperlegible-Regular.ttf
- RobotoCondensed.ttf: ofl/robotocondensed/RobotoCondensed[wght].ttf
