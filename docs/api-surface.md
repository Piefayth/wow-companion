# The API surface, and the terms of each part

Generated by `tools/api_surface.py`; do not edit by hand. Every name is in `api-surface.tsv` (grep it: `grep -P '^C_Spell\.' docs/api-surface.tsv`).

**10,957 names** exist in this client (1.60.1.70862). 6,329 have a signature in the client's own docs; 6,722 are on the wiki's list; Blizzard's UI code that loads in Forever calls 8,888 of them.

## The tiers

Strictest first; a name lands in the first that applies.

| Tier | Names | Terms |
|---|---:|---|
| **protected** | 135 | Not callable from addon code at all. Route: a secure button the player presses (macro text), never a call. |
| **hardware** | 23 | Only inside the player's own press (a click or key handler). Route: a secure button. |
| **nocombat** | 27 | Callable, but only out of combat (InCombatLockdown() false). |
| **restricted** | 193 | Flagged HasRestrictions: some contexts refuse it, and the docs do not say which. Read Blizzard's callers first; test once, out of combat. |
| **secret** | 222 | Callable, but its results can come back as secret values (in combat, encounters, PvP, restricted units): opaque to addon code, so no comparing, maths or string work on them; they can only be handed to display widgets. |
| **precondition** | 208 | Callable once its situation holds: its data loaded (Requires...: friend list, clubs, a valid slot, a cvar), or, per the wiki, outside instances (noinstance) or in a group (grouponly). |
| **read** | 3,454 | Reads game state, no documented condition, and Blizzard's Forever UI calls it: the safe, well-trodden part. Still never call in bulk: one read crashed the client in C. |
| **change** | 835 | Changes game state (Set, Add, Use, Buy, Post, Delete...), no documented condition, and Blizzard's Forever UI calls it. Usually needs a context the docs omit (a vendor, the auction house, a mailbox open). Read how Blizzard calls it first. |
| **dormant** | 1,878 | No Blizzard code that loads in Forever calls it. Either the feature is absent here (garrisons, delves, housing), or Blizzard does the same job with another function (it lists your auctions with GetOwnedAuctionInfo, not GetOwnedAuctions): use the one Blizzard calls. Also deprecated ones. |
| **blizzard-lua** | 3,938 | Not engine API: a Lua function Blizzard's own interface defines (docs/wow-ui-source). Callable, but it then runs as your code, tainted. Harmless for pure helpers (MinutesToTime); for anything that shows, hides, moves or sets Blizzard's frames it is the taint that broke A and B. Read its source first. |
| **unknown** | 44 | Undocumented by the client and untagged by the wiki: nothing says. Blizzard's own use, if any, is the evidence. |

## Rules over all of it

- **Taint.** Anything addon code touches is tainted. A protected action reached *through* tainted state is blocked ("Interface action failed"), even if the call itself was allowed. Never set a property of Blizzard's frames or replace their globals; measure new paths with the `issecurevariable` diff.

- **Secret values.** `SecretArguments=AllowedWhenUntainted` (most functions) means only Blizzard's untainted code may pass a secret value in; addon code passing one errors. `AllowedWhenTainted` functions accept them from anyone; `NotAllowed` from no one. Test with `issecretvalue(v)` / `canaccessvalue(v)` before using a result that might be secret.

- **Wiki tags** (warcraft.wiki.gg, retail-era): `protected` only secure code; `hwevent` needs keyboard/mouse/pad input; `nocombat` not in combat; `noscript` not from `/script` in chat, which addon code (our `lua` steps, our addons) is not; `noinstance` not in dungeons or raids; `deprecated` probably non-functional; `framexml` defined in Blizzard's Lua.

- **This project's own terms**, on top of the client's: configuration, not play; out of combat; chat placed for the player to send, never sent; nothing that deletes items, trades, spends gold or leaves groups (the Lua sandbox refuses these by name).

- **Evidence, best first:** measured here (`ours` column) > Blizzard calls it (`blizzard_uses` > 0, read how) > documented with no condition > wiki-listed > nothing. The wiki is retail-era; where it and a measurement disagree, the measurement wins (e.g. `PlaceAction`: untagged, and measured clean).
